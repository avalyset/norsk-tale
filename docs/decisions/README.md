# Beslutninger (ADR)

Arkitekturbeslutninger for norsk-tale, med prefiks NTA-. NTA-0001 til NTA-0006
ble skrevet i etterkant, 2026-10-19, etter at beslutningene var tatt og målt. De
er derfor i fortid. Hver påstand kan etterprøves mot testen, målingen, committen
eller registreringen det lenkes til.
